# Design-time artwork and resources

- `palette/`: one 24px RGBA PNG per registered component (141). These are the
  icons the IDE shows on the component palette.
- `delphi-obd-mark.png`: 128px package mark (GetIt listing), drawn from the dial
  gauge icon.
- `resources.json`: resource name, type and PNG path for every registered
  component.

All of it is generated by `tools/designtime_icons.py` from simple vector shapes:
a charcoal tile (`#25262b`, edge `#5c636a`) with the glyph in the ERDesigns theme
colours — orange `#f08818` / `#f0923a` / `#b4530a`, light surface `#f8f9fa`, and
the status colours success `#28a745`, warning `#ffc107`, danger `#dc3545` and
info `#17a2b8`. These are the same tokens the dashboard light and dark palettes
in `src/UI/ERD.UI.Types.pas` use. The dark tile keeps the glyphs readable on both
the light and the dark IDE theme.

Regenerate and rebuild `src/DesignTime/ERD.Design.Icons.res` with:

```sh
python3 tools/designtime_icons.py --write
python3 tools/designtime_resources.py --write
```

Without `--write` both tools check that the tracked files are current; CI runs
those checks. `python3 tools/designtime_icons.py --sheet /tmp/icons.png` writes
an 8x enlarged contact sheet for review. Do not hand-edit the PNGs or the binary
resource: change the drawing in the generator instead.

Check the icons in the IDE at 100 %, 150 % and 200 % scaling and in the light and
dark IDE themes during the [Delphi validation pass](../../docs/delphi-validation.md).
