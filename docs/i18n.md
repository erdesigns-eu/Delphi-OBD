# Localisation

Delphi-OBD uses `ERD.I18n` for runtime localisation. The unit ships with compiled-in English defaults and can load UTF-8 JSON catalogues from `languages/*.json`.

## Languages

Catalogues marked `"status": "draft"` are machine translations that a native speaker has not reviewed yet; an application can show that next to the language name (`TOBDLanguageInfo.Status`). Regional languages (Basque, Galician, Welsh, Frisian and others) and a Latin-script Serbian catalogue (`sr-latn`) can be added by dropping another JSON file in the folder.

`OBDDefaultLanguageCode` maps the Windows UI language (or `LANG` elsewhere) to one of these codes, including Bokmål / Nynorsk and Croatian / Bosnian / Serbian, and returns `en` otherwise.

Language files follow `languages/_schema/i18n-catalog.schema.json`:

```json
{
  "language": "nl",
  "name": "Nederlands",
  "englishName": "Dutch",
  "version": 1,
  "status": "draft",
  "strings": {
    "ui.dtc.read": "Codes lezen",
    "ui.dtc.codeCount.plural": {"one": "%d code", "other": "%d codes"}
  }
}
```

Keys are dotted and namespaced as `ui.*`, `service.*`, `app.*`, `common.*` or `status.*`. Placeholders use Delphi `Format` syntax and must match in every language. Use:

```pascal
Caption := Tr('ui.dtc.read', 'Read codes');
Text := TrFmt('ui.dtc.footer.summary', '%d codes - %d stored, %d pending, %d permanent', [Total, Stored, Pending, Permanent]);
```

## Plurals

`TrPlural` picks the CLDR cardinal plural category of the language that supplied the text (`OBDPluralCategory`). Every plural entry has `one` and `other`; the languages that need them add `zero`, `two`, `few` or `many`:

| Categories | Languages |
|---|---|
| `one`, `other` | all others (French uses `one` for 0 and 1; Icelandic and Macedonian for 1, 21, 31, …) |
| `zero`, `one`, `other` | `lv` |
| `one`, `few`, `other` | `cs`, `sk`, `hr`, `sr`, `bs`, `lt`, `ro` |
| `one`, `few`, `many`, `other` | `pl`, `ru`, `uk`, `be` |
| `one`, `two`, `few`, `other` | `sl` |
| `one`, `two`, `few`, `many`, `other` | `ga`, `mt` |

```json
"ui.dtc.codeCount.plural": {"one": "%d kod", "few": "%d kody", "many": "%d kodów", "other": "%d kodu"}
```

A missing category falls back to `other`.

## Checking

Run `python3 tools/i18n_check.py` before release. It validates schema coverage, key parity, placeholder parity (every plural form against the English `other` form), the plural categories of each language, that each file name matches its `language` code, and `Tr*('key')` usage under `src/`.
